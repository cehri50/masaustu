# 🚀 Pardus & Kapadokya Temalı Yapay Zeka Arayüzü

Bu proje; modern yapay zeka teknolojilerini, **Pardus Linux** esnekliği ve **Kapadokya**'nın eşsiz ruhuyla bir araya getiren özel bir web arayüzü çalışmasıdır. Vite tabanlı modern mimarisiyle yüksek hızda çalışır ve kullanıcıya akıcı bir deneyim sunar.

---

## ✨ Proje Özellikleri

* **Özel Masaüstü Entegrasyonu:** Pardus (KDE + Wayland) sistemleriyle tam uyumlu ve optimize arayüz.
* **Yapay Zeka Destekli:** Arka planda Gemini API gücüyle çalışan akıllı asistan yapısı.
* **Hızlı ve Hafif:** Vite ve TypeScript mimarisi sayesinde milisaniyeler içinde yüklenen sayfalar.
